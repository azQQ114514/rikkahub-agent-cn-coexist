# 修改说明（v2.4.10 中文共存版）

本文档详细列出本分支 APK 相对上游 RikkaHub Agent v2.4.10 的全部修改，依 AGPL-3.0 要求公开。

## 基线版本
- 上游：RikkaHub Agent v2.4.10（versionCode 177）
- 修改方式：静态 smali / dex 补丁 + 资源替换（非源码编译），补丁点均记录于本文档

## 1. 全量中文化

### 1.1 资源翻译
- resources：2183 条资源 key 全部翻译为简体中文（strings.xml 等），并移除其他语言目录只保留中文

### 1.2 硬编码文本插桩
- Compose 渲染层插桩，覆盖资源文件够不到的硬编码英文界面文本 241 处（含对话悬浮窗提示）

### 1.3 权限说明人性化
- 44 条权限请求常量说明改写为可读性优先的大白话

### 1.4 术语一致性审计
- 2749 条术语条目全量审计，同一英文源的翻译口径统一
- 用户决策优先于机器口径（例：导入对话框标题保留"导入供应商配置"）

### 1.5 不翻译策略
- 技术格式串保持原文不翻译，例如 shell 退出码显示 exit %s（保留原格式更直观易懂）

## 2. 导入上限 256MB → 10GB
- 官方限制：工作区单次文件导入最大 256MB
- 修改点：importFile 复制循环与 writeText 中两处被 R8 内联的大小比较检查
- 修改方式：二进制补丁比较常量至 10GB（10737418240）

## 3. 共存安装
- 包名：改为 excp.rikkahub.zhcn（原版包名保留给官方客户端）
- versionCode：188
- versionName：2.4.10
- 签名：独立自签证书，仅 v2/v3 签名方案，可与官方版并存安装

## 4. 随附资料
- 完整翻译库（resources / hardcode / humanize 共 2400+ 条）作为 Release 附件公开：rikkahub_l10n_db.json
